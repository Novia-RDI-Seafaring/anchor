# Document raster geometry

Document cards and the raster modal read source-page dimensions through
`web/src/lib/documentPageGeometry.ts`. Silver's `build_pages_meta` produces
`pages.meta.json`; the gold-map endpoint exposes it as `pages_meta`:

```json
{
  "bbox_origin": "top-left",
  "pages": {
    "1": { "page_size": [600, 800] },
    "2": { "page_size": [800, 600] }
  }
}
```

`page_size` is width and height in source PDF points. It is independent of
the raster's DPI and pixel dimensions. Each page has its own dimensions.
The compatibility parser also accepts the previous flat consumer shape,
`{ "1": { "width": 600, "height": 800 } }`. It requires positive finite
numeric dimensions. Malformed canonical metadata does not fall through to
legacy fields. Explicit non-top-left metadata is unsupported.

The parser returns page-keyed `DocumentPageGeometry` values. A missing page
means unknown geometry. The page image remains visible, precise overlays are
omitted, and a text status explains that page dimensions are unknown. Image
dimensions alone cannot establish source dimensions, so there is no assumed
DPI fallback.

Both raster consumers use `bboxToImageRect`. The card requests a 100-by-100
target to obtain percentages; the modal requests the loaded image's natural
pixel dimensions for its SVG overlay. For an unrotated page of size W by H,
the percentages are x/W, y/H, width/W and height/H, multiplied by 100.
Card resizing and canvas zoom scale the image and percentages together.
Stored bboxes and `coord_origin` are unchanged.

The frontend contract fixture is generated by
`tests/fixtures/document_page_geometry.py` using the real renderer, silver
producer and gold-map store reader. The backend contract test regenerates
and compares that payload with the frontend fixture. To regenerate it:

```bash
uv run python -m tests.fixtures.document_page_geometry web/src/lib/fixtures/documentPageGeometry.json
```

Rotation, crop-box and UserUnit transforms belong to the separate PDF viewport
contract. This adapter performs no such transformations.
